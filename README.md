# WorkoutChallenge

A motivational running challenge app focused on consistency and habit building.

## Stack

React + TypeScript + Vite, React Router, Tailwind CSS, shadcn/ui, Firebase (Auth, Firestore, Cloud Messaging, Cloud Functions), deployed on Vercel.

## Development

```bash
npm install
cp .env.example .env.local   # fill in your Firebase project credentials
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run test` — run unit tests (Vitest)
- `npm run lint` — lint with ESLint
- `npm run format` — format with Prettier
- `npm run typecheck` — strict TypeScript check
